# Task 11: Implement Recurring Instance Auto-Generation per Month

- **Epic:** Recurring Transactions & Monthly Overrides
- **Phase:** phase-1
- **Status:** Done
- **Story Points:** 8

---

## اقدامات انجام‌شده

1. **موتور تولید خودکار نمونه‌های ماهانه (`getRecurringInstancesForMonth`):**
   - بررسی تطابق بازه زمانی قانون با ماه انتخابی کاربر (`startMonth <= jalaliMonth <= endMonth`).
   - استخراج شناسه یکتای مجازی برای هر نمونه به شکل `rec_inst_{ruleId}_{jalaliMonth}`.
   - تولید تاریخ شمسی بر اساس فیلد `dayOfMonth` قانون پایه.

2. **تلفیق در داشبورد و جدول تراکنش‌ها:**
   - الحاق نمونه‌های دوره‌ای به تراکنش‌های عادی در `DashboardManager`:
     - محاسبه درآمد و هزینه‌های دوره‌ای در کارت‌های خلاصه (KPI).
     - محاسبه سهم دسته‌های دوره‌ای در نمودار دونات Chart.js.
   - نمایش در جدول تراکنش‌ها همراه با برچسب مشخص `دوره‌ای` و نشانگر وضعیت استثنا.

3. **حفظ استقلال داده‌ها:**
   - نمونه‌های دوره‌ای به صورت مجازی محاسبه می‌شوند و نیازی به ذخیره تکراری در دیتابیس ندارند، در نتیجه حجم دیتابیس لوکال بدون مصرف بیهوده سبک باقی می‌ماند.
