## اقدامات انجام‌شده

1. **طراحی هویت بصری و استایل مینیمال Notion (`assets/css/style.css`):**
   - تعریف متغیرهای تم روشن (`--bg-app: #ffffff`, `--bg-subtle: #f7f6f3`, `--border-main: #e3e2de`, `--text-main: #37352f`).
   - تعریف متغیرهای تم تیره (`--bg-app: #191919`, `--bg-panel: #202020`, `--border-main: #373737`).
   - تنظیم تایپوگرافی رسمی و پیاده‌سازی فونت وب وزیرمتن (Vazirmatn) با اوزان Regular, Medium, Bold.
   - چیدمان دوردیفه و دوستونه (ستون چپ فرم‌ها و نمودار، ستون راست ریز تراکنش‌ها) متناسب با اندازه صفحه.

2. **سیستم آیکون‌ها و پالت‌های رنگی دسته‌بندی‌ها (Category Palette System):**
   - جایگزینی ایموجی‌های نامتعارف با برچسب‌های رنگی ساختاریافته (Pill Badges همراه با Color Dot گرد).
   - پالت رنگی ۱۰ گانه الهام‌گرفته از نوشن (`#e16b5a`, `#e89a3c`, `#d4b138`, `#4dab9a`, `#2383e2`, `#9065b0`, `#c15c8a`, `#787774`, `#4472c4`, `#548235`).
   - انتخابگر زنده رنگ‌ها به صورت گرد در مودال تعریف و ویرایش دسته‌بندی‌ها.

3. **واکنش‌گرایی (Responsive Layout):**
   - بریک‌پوینت ۸۴۰ پیکسل برای تطبیق خودکار ستون‌های داشبورد به حالت تک‌ستونه عمودی روی موبایل و تبلت.
   - اسکرول افقی ایمن جدول تراکنش‌ها (`.data-table-wrap`) در صفحات کوچک برای حفظ خوانایی مقادیر و دکمه‌ها.
