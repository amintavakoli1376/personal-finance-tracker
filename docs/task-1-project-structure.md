# Task 1: Initialize Project Structure

- **Epic:** Project Setup & Technical Foundation
- **Phase:** phase-1
- **Status:** Done
- **Story Points:** 3

---

## اقدامات انجام‌شده

1. **ایجاد اسکلت اولیه و پوشه‌بندی:**
   - ساختار پوشه‌های `assets/css/`, `assets/js/`, `assets/vendor/`, `docs/` ایجاد شد.
   - مخزن گیت با شاخه اصلی `main` در مسیر `/root/personal-finance-tracker` مقداردهی اولیه شد.

2. **طراحی ساختار رابط کاربری (`index.html`):**
   - هدر برنامه شامل عنوان، دکمه تغییر حالت تاریک/روشن و دکمه خروجی اکسل.
   - نوار انتخاب ماه شمسی (`month-selector-bar`) با دکمه‌های ناوبری به ماه‌های قبل، بعد و امروز.
   - گرید کارت‌های خلاصه مالی (مجموع درآمد، مجموع هزینه و تراز خالص ماه).
   - بخش دو ستونه:
     - ستون چپ: پنل نمودار دونات دسته‌بندی‌ها + فرم ثبت سریع تراکنش جدید.
     - ستون راست: پنل جدول ریز تراکنش‌های ماه با نشانگرهای درآمد/هزینه و برچسب‌های وضعیت.

3. **سیستم استایل و تایپوگرافی (`assets/css/style.css`):**
   - پیاده‌سازی متغیرهای CSS بر پایه تم مینیمال Notion (پالت‌های خنثی، خطوط کم‌رنگ، حذف ایموجی‌های زاید).
   - پشتیبانی از حالت‌های تاریک و روشن (`[data-theme="dark"]`).
   - تنظیم فونت فارسی استاندارد وزیرمتن (Vazirmatn) با چینش کامل راست به چپ (RTL).
   - طراحی واکنش‌گرا (Responsive) برای موبایل و دسکتاپ.

4. **اسکریپت راه‌اندازی و پیوندها (`assets/js/app.js`):**
   - مقداردهی اولیه تم برنامه از `localStorage` و مدیریت رویداد دکمه تغییر تم.
   - ایجاد پیوندهای `style.css` و `script.js` در روت پروژه برای پشتیبانی از حالت‌های مختلف ارجاع.

5. **راهنمای اجرا و توسعه (`README.md`):**
   - دستورالعمل‌های اجرای مستقل (Zero-Build) به روش‌های باز کردن مستقیم فایل، افزونه Live Server و سرور محلی پایتون.
